# 《我的听书》订阅源合集

因为《我的听书》APP 已停止维护。本仓库汇总多个《我的听书》自定义源 jar 包与对应的订阅入口 `external_sources.json`，方便一键订阅导入或离线使用。仅供自用。

**导入方式（订阅）**：在 App 的「自定义源管理 → 右上角添加订阅」中，填入下方对应源的 raw 地址即可。

**导入方式（离线）**：把 jar 直接复制到手机 `Android/data/com.github.eprendre.tingshu/files/jars/` 目录，App 启动时会自动加载（无需 json）。

---

## 一、本仓库唯一自维护源：luov（B 站 + 广播 + 听听FM回听）

`sources_by_luov.jar` 是**本仓库唯一新编写、长期维护**的源，相对 B 站官方内容做了**兼容性保留 + 功能新增**：

- **订阅标题**：本订阅在 App「源管理」页显示的标题为 **「订阅源：听书+直播源」**
- **哔哩（新）（B 站子源）** —— App 源列表中的显示名即为「哔哩（新）」。
  - 保留并兼容原有能力：搜索、分类（6 个标签）、合集视频连播；
  - 相比于旧的官方源，**新增「合集」连播**：支持 B 站 `ugc_season` 合集（原 App 只能抓单集、分P，无法合集连播），自动展开合集内每一集、以及每集合的每个分 P，生成可连续播放的条目。

> ✅ **可以和官方源并存。** 本「哔哩（新）」是官方旧源的**超集**（旧功能全保留 + 新增合集连播），两者用完全相同的 B 站搜索接口。本源分类为「听书2」，与官方源的「听书」分开，App 里显示为两个分类、搜索不再同步——你可以手动选择用哪个源搜索，按需启用即可。

- **央广 / 地方广播**：国家广播 19 套（央广 16 套 + 国广 CRI 3 套）+ 地方广播 31 个省级行政区（含央广接口没有的天津），统一收进同一个源——分类菜单中「央广」为第一个分类，其后依次各省/区/直辖市，共 31 个分类；每个台都带自己的台标。并新增了地市覆盖。

- **听听FM·回听/专辑**：免费广播回听 + 免费点播专辑。
  - **搜索**：输入任意关键词（电台名/节目/专辑/音频），一次列出四类结果；也可粘贴听听FM 分享链接（如 `https://mobile.tingtingfm.com/v3/vod/2/3aMvs1xX5J`）或 11 位 ID 直接导入。
  - **分类**：热门节目（空关键词节目列表，实测 20/20 全可播、支持翻页）、7 个北京广播台节目回听（**交通 / 新闻 / 音乐 / 文艺 / 副中心 / 京津冀 / 听听FM**，每个 tab 的电台 ID 均实测节目表非空）、免费专辑（**400+ 个**，前 20 个 100% 有免费集）。点某个台 → 列当天/昨天节目 → 展开往期回听连播。
  - **只做免费内容**：VIP 付费专辑不做，付费集按 `is_free` 自动过滤。

导入地址：

```text
https://raw.githubusercontent.com/Rorwey/tingshu-luov-source/main/external_sources.json
```

文件说明：

- `external_sources.json`：luov 源的订阅入口（当前 version = 25，版本号变化会触发 App 重新拉取）。
- `sources_by_luov.jar`：luov 源解析包。
- `CHANGELOG.md`：**版本更新日志**——从 v2 到当前版本，每个版本的变更内容、台数、jar 体积、对应 commit 与已知短板；文末另列「已实测但不接入」的事项。
- `STREAMS.md`：**直播源与封面清单 / 核验手册**——所有已接入流的 URL、封面图、签名方式、活性检测结果，以及备选（实测可用但未接入）与已排除流的清单和原因、可复制的核验命令。

> 参考与致谢：本 luov 源基于原作者 **eprendre** 的《我的听书》框架与示例编写（自定义源项目 `CustomSources`、源编写逻辑均来源于此），借助AI协助。参考项目地址：<https://github.com/eprendre/tingshu> 。本仓库仅在此框架基础上新增合集连播与广播 / 电视直播能力，著作权尊重原框架作者。
>
> 广播直链另参考了 GitHub 公开电台清单（`kilvn/iptv`、`hcm82/iptvradio`、`jiqiao/tv`、`iptv-org/iptv`、`fanmingming/live` 等）、江西广电鉴权的公开实现（`linux-jin/TvBox` 江西电视台 PC 官网代理源码、恩山无线论坛相关讨论）与各地广电官网（`www.cnr.cn/gbzb/`、`jxntv.cn`、`www.jxgdw.cn`、`www.nctv.net.cn`）。所有收录的流均**逐条实测**：主列表 → 子列表 → ts 分片 HTTP 200、无 `#EXT-X-KEY` 加密、播放列表 8 秒双快照实时滚动；静态缓存（如湘潭广电）、伪装成 200 的错误响应、停播 / 404 流一律排除。需要鉴权的官方流不硬编码签名，改为播放时动态获取。完整清单见 `STREAMS.md`。
