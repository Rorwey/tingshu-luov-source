# 《我的听书》订阅源合集

因为《我的听书》APP 已停止维护。本仓库汇总多个《我的听书》自定义源 jar 包与对应的订阅入口 `external_sources.json`，方便一键订阅导入或离线使用。仅供自用。

**导入方式（订阅）**：在 App 的「自定义源管理 → 右上角添加订阅」中，填入下方对应源的 raw 地址即可。

**导入方式（离线）**：把 jar 直接复制到手机 `Android/data/com.github.eprendre.tingshu/files/jars/` 目录，App 启动时会自动加载（无需 json）。

---

## 一、本仓库唯一自维护源：luov（B 站 + 广播 / 电视直播）

`sources_by_luov.jar` 是**本仓库唯一新编写、长期维护**的源，相对 B 站官方内容做了**兼容性保留 + 功能新增**：

- **订阅标题**：本订阅在 App「源管理」页显示的标题为 **「订阅源：听书+直播源」**
- **哔哩（新）（B 站子源）** —— App 源列表中的显示名即为「哔哩（新）」。
  - 保留并兼容原有能力：搜索、分类（6 个标签）、合集视频连播；
  - 相比于旧的官方源，**新增「合集」连播**：支持 B 站 `ugc_season` 合集（原 App 只能抓单集、分P，无法合集连播），自动展开合集内每一集、以及每集合的每个分 P，生成可连续播放的条目。

> ⚠️ **重要：请勿同时启用原作者的官方「哔哩哔哩」源。** 本「哔哩（新）」是官方旧源的**超集**（旧功能全保留 + 新增合集连播），且两者使用完全相同的 B 站搜索接口与域名。若同时启用，App 在全局搜索时会对同一关键词向 B 站发两条重复请求，触发风控限流 / 结果归属竞态，表现为「其中一个哔哩源搜索空白、时好时坏」。请在本仓库导入的 `sources_by_eprendre` 等第三方源中，**关闭或删除官方旧「哔哩哔哩」源**，仅保留本「哔哩（新）」即可。

- **央广 / 地方广播**：国家广播 19 套（央广 16 套 + 国广 CRI 3 套）+ 地方广播 31 个省级行政区（含央广接口没有的天津），统一收进同一个源——分类菜单中「央广」为第一个分类，其后依次各省/区/直辖市，共 31 个分类；每个台都带自己的台标。
  - **v8 修复「中央台只有两个能播」**：此前源里把国家台流地址的 `?key=&time=` 鉴权签名统一去掉了，实测 19 套中只有中国之声、经济之声（及 3 个国广 CRI 台）可裸访问，其余 14 个 `ngcdn00X` 台一律 403「网络错误」。现改为：列表只保存**稳定裸路径**，点击播放时重新请求 `apppc.cnr.cn/national` 注入**最新签名**（该签名每次请求都会重新生成、但不绑定 UA/Referer），19 套恢复可用，且不会把很快过期的签名硬编码进 jar 或收藏记录。
  - **v9 中央台再修复 + 动态签名加固**：实测 national 接口返回 **2 个内容完全相同的分类**（各 19 条），旧版遍历全部导致列表出现 38 个重复台，现按裸 URL 去重恢复为 19 套。另外给 `StreamSigner` 加了**进程内签名缓存**：列表页拿到签名即预热，播放时仍联网刷新为最新值，若接口偶发失败则用缓存兜底，不再退化成 403 裸链（实测央广 `time` 只是生成时刻，12 分钟前的旧签名仍可播）。订阅源本身是 dex-jar、可跑任意代码，所以「动态」完全可行；但**纯本地按时间算签名做不到**（`key` 含服务端密钥，多种 md5 组合实测均不命中），必须点播放时联网反查一次。
  - **湖南 / 江西扩展**：在央广官方接口返回的省台之后，补充实测可用的省级台（湖南交通 / 经济 / 金鹰之声 / 音乐之声）与地市级电台；**市级台按车牌字母序排列**（湖南：湘A 长沙 → 湘B 株洲；江西：赣A 南昌 → 赣B 赣州 → 赣G 九江）。
    - **江西广电自营 6 个频率全部接入**（台名经 `jxntv.cn` 官网核实）：故事 FM96.9 / 旅游 FM97.4 / 财经 FM99.2 / 音乐 FM103.4 / 新闻 FM104.4 / 交通 FM105.4，均为官方直连、无签名。
    - **v9 曾新增央广 CDN 备用线路 3 条**（江西综合新闻 / 信息交通 / 音乐广播）；**v10 已删除**——它们与 `local` 接口返回的江西台是同一 URL，会在列表里重复出现。
    - **v9 新增九江交通广播 FM88.4/88.9**（蜻蜓线路，活性检测通过），补齐赣G；封面暂用江西交通类台标占位。
    - **新增南昌广播电视台官网直连 2 条**：新闻综合频率 FM91.7、南昌交通广播 FM95.1（`only-audio=1` 纯音频）。官网流带 `txSecret/txTime`（约 30 分钟滚动刷新、裸地址 403），同样在播放时从官网直播页动态取最新签名。原有蜻蜓「南昌交通音乐广播」保留为「（备用）」。
  - 已过滤失效的「湖南年代音乐台」及官网公告停播的江西都市 / 民生 / 农村广播。
  - **v11 全面补全广播源（新增 950 台，覆盖 31 个省级行政区、251 个地市，`RadioData.kt` 数据表）**：改用蜻蜓 FM 的区域频道目录（`rapi.qingting.fm/categories/{分类}/channels` 分页遍历 13 个分类，抓全 1079 个频道）按「省 · 市」归位，再与央广接口已有台、湖南/江西官网直连台去重：
    - **天津**：央广 `local/list` 只列 30 个省、**根本没有天津**，现单独补一个「天津」分类（id `tj`），内容全部走数据表。
    - **台数最多的省**：山东 92（15 市）、江苏 76（13 市）、河北 70（11 市）、河南 68（20 市）、浙江 64（10 市）、四川 61（19 市）、广东 52（18 市）、湖北 43（13 市）、安徽 38（13 市）、山西 36、湖南 36、新疆 36。
    - **地市覆盖**：河南 20 市、四川 19 市、广东 18 市、山东 15 市、江苏 13 市、安徽 13 市、湖北 13 市、云南 12 市、河北 11 市、新疆 11 市、浙江 10 市、湖南 10 市 —— 基本做到每个地级市都有台。
    - **命名规则**：台名里没有城市名时自动补 `城市·` 前缀（如「保定·曲阳融媒FM90.4」「烟台·仙境之声」）；自治州按民族名截断（「红河哈尼族彝族自治州」→「红河」）；同城同频（如 104.8 出现两个名字）只保留名字更规范的一条。
    - **每台独立台标**：优先用蜻蜓 `pic.qtfm.cn` 的频道封面（约 900 张，实测 200 / image 格式），缺失才回退该省默认台标。
    - **数据源短板（据实说明）**：蜻蜓对西藏（1 个频道）、宁夏（3）、青海（4）、甘肃（7）、天津（2）收录本身很少，这几地台数偏少是数据源限制，不是筛选过严；本地台已全部接完，暂无可补的公开源。
    - **收录规则不变**：主列表 200 → 首个分片 / 子列表 200 → 间隔 8 秒双快照 `MEDIA-SEQUENCE` 必须增长；加密（`#EXT-X-KEY`）、404、定格流一律排除。全部 1073 条候选中 1021 条分类目录 + 52 条旧 id 通过，去重后入表 950 条。逐省统计见 `STREAMS.md` 第 9 节。
    - **工程注意**：数据表约 100KB，超过 JVM 单个字符串常量 65535 字节上限（`UTF8 string too large`），因此 `RadioData.kt` 已按 52KB 拆成 `C1`/`C2` 两块，在 `TABLE` 里 `by lazy` 合并 —— 以后追加数据往对应块按行插入即可。
- **央视 / 地方卫视（电视源，独立子源）**：**命名规则 —— 只有伴音才在名称里加「（伴音）」，真正的视频流不加任何标注**。
  - 分类「卫视伴音」：湖南卫视（伴音）、江西卫视（伴音）—— 央广 CDN 纯音频直播、不加密、带台标封面，播放时无画面仅有声音。
  - 分类「南昌电视」：南昌新闻综合频道 / 文旅频道 / 资讯频道 —— 来自 `www.nctv.net.cn` 官网的**官方视频流**（名称不加标注、不加密、带官网台标）。本 App 为音频播放器，播放时只取声音；签名同样播放时动态获取。
  - 央视各频道因 ChinaDRM 加密（不加密的官方普通流已下线）暂不接入，源码注释中有完整诊断记录。
  - **江西省级电视频道（v9 核查后仍未接入）**：优先查官网，已完整逆出取流链（`cdnauth.jxgdw.com/liveauth/pc` 换 token → `yun-live.jxtvcn.com.cn` 播放），但播放 CDN 一律 403；按 GitHub 公开实现 `linux-jin/TvBox` 的江西电视台代理源码与恩山论坛算法（签名头 / 15 位时间戳 / 去掉 uuid / 只带 token / 备用域名）共 36 种组合复现仍全部 403，判断为 CDN 侧 IP / 风控校验。GitHub IPTV 清单里的江西频道均为运营商内网 IP，公网全部超时。按「实在无法逆向就算了」放弃，详见 `STREAMS.md` 第 8 节。

导入地址：

```text
https://raw.githubusercontent.com/Rorwey/tingshu-luov-source/main/external_sources.json
```

文件说明：

- `external_sources.json`：luov 源的订阅入口（当前 version = 11，版本号变化会触发 App 重新拉取）。
- `sources_by_luov.jar`：luov 源解析包。
- `STREAMS.md`：**直播源与封面清单 / 核验手册**——所有已接入流的 URL、封面图、签名方式、活性检测结果，以及备选（实测可用但未接入）与已排除流的清单和原因、可复制的核验命令。

> 参考与致谢：本 luov 源基于原作者 **eprendre** 的《我的听书》框架与示例编写（自定义源项目 `CustomSources`、源编写逻辑均来源于此），借助AI协助。参考项目地址：https://github.com/eprendre/tingshu 。本仓库仅在此框架基础上新增合集连播与广播 / 电视直播能力，著作权尊重原框架作者。
>
> 广播 / 电视直链另参考了 GitHub 公开电台清单（`kilvn/iptv`、`hcm82/iptvradio`、`jiqiao/tv`、`iptv-org/iptv`、`fanmingming/live` 等）、江西广电鉴权的公开实现（`linux-jin/TvBox` 江西电视台 PC 官网代理源码、恩山无线论坛相关讨论）与各地广电官网（`www.cnr.cn/gbzb/`、`jxntv.cn`、`www.jxgdw.cn`、`www.nctv.net.cn`）。所有收录的流均**逐条实测**：主列表 → 子列表 → ts 分片 HTTP 200、无 `#EXT-X-KEY` 加密、播放列表 8 秒双快照实时滚动；静态缓存（如湘潭广电）、伪装成 200 的错误响应、停播 / 404 流一律排除。需要鉴权的官方流不硬编码签名，改为播放时动态获取。完整清单见 `STREAMS.md`。
